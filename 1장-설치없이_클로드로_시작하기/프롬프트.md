## 1.2.2 첫 프롬프트

```
조선시대 심리테스트를 만들어줘. "나는 전생에 뭐였을까"

- 질문 12개, 각 질문마다 선택지 2개
- 선택지를 고르면 유형에 점수가 쌓이고, 제일 높은 유형이 결과로 나온다
- 결과는 아래 9가지 중 하나:
  장사꾼(한양의 소문난 장사꾼) / 요리사(궁궐의 왕실 요리사) /
  정보꾼(한양 최고의 정보꾼) / 선비(과거시험 준비생) /
  궁녀(왕실의 궁녀) / 보부상(전국을 떠돌던 보부상) /
  대필가(연애편지 대필가) / 장난꾸러기(한양의 장난꾸러기) /
  무관(궁궐을 지키던 무관)

- 결과 화면에는 "그래서 지금" 이라는 제목으로 요즘 모습 3줄을 보여줘.
- 잘 맞는 유형 하나, 상극인 유형 하나도 같이 보여줘.
```

## 1.3.2 디자인 바꾸기

```

```

## 1.3.3 결과가 쏠리지 않는지 확인하기

```
결과가 한쪽으로 쏠리지 않는지 확인해줘. 무작위로 여러 번 돌려서 유형별로 몇 %씩 나오는지 알려줘.
```

```
쏠린 유형이 있으면 선택지 순서를 섞어서 고르게 맞춰줘.
```

## 1.3.4 구체적으로 말할수록 잘 나온다

```
질문을 전부 회사 생활에서 벌어지는 상황으로 바꿔줘.
성격을 대놓고 묻지 말고, 상황을 주고 어떻게 하는지 고르게 해줘.
예) "회의가 예정보다 일찍 끝났다" → "바로 자리로 돌아간다 / 커피부터 한 잔 한다"
```
