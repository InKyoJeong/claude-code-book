# 2장 클로드 코드 설치하고 내 컴퓨터에 일 시키기

책에 나오는 순서대로 모았습니다. 상자 오른쪽 위의 복사 버튼을 누르면 그대로 복사됩니다.

## 2.4.1 처음 실행하고 로그인하기

```
지금 어느 폴더에 있어?
```

## 2.4.2 클로드에게 파일 만들게 하기

```
이 폴더에 연습용 파일을 어지럽게 만들어줘. 다운로드 폴더 같은 느낌으로.

- 스크린샷 5개, PDF 3개, 이미지 4개, 엑셀 2개, 압축파일 2개
- 파일 이름은 실제처럼 지저분하게 해줘.
예) 무제(1).pdf / download.pdf / KakaoTalk_20260315_143022.jpg
- 문서 세 개는 안에 내용도 채워줘. 임대차 계약서, 영수증, 회의록.
- 메모도 몇 개 텍스트로 만들어줘. 여행 다녀와서 다음에 챙길 것까지 적어 둔 메모, 장보기 목록 같은 거.
- 내용은 전부 지어낸 걸로 해줘. 실제 이름이나 주소는 넣지 말고.
```

## 2.7.2 먼저 물어보기

```
@카드이용내역1.xlsx @카드이용내역2.xlsx 이 두 파일에 뭐가 들어있는지 알려줘.
```

## 2.7.3 항목별로 묶기

```
@카드이용내역1.xlsx @카드이용내역2.xlsx 두 카드 내역을 합쳐서 한 달 가계부를 만들어줘. 브라우저에서 열어 볼 수 있는 HTML 파일로 이 폴더에 만들어 줘.

- 가게 이름 보고 항목별로 묶어줘
- 이번 달에 쓴 돈을 셋으로 갈라줘. 매달 정해진 금액이 나가는 고정비, 매달 비슷하게 나가는 생활비, 이번 달에만 나간 큰 지출

그리고 이름만 봐서는 뭔지 모르겠는 가게가 있으면 따로 알려줘.
```

## 2.7.4 내가 알려줘야 하는 것

```
아까 확인 필요하다고 한 가게들, 알려줄게.

- 김치 도방, 매화방 3호점, 우리주막나무터, 광화문미소 6호점, 하루반 9호점, 멘노아라 : 다 점심 먹은거야.
- 원리터(1L) 2호점, 블루씨 11호점 : 카페 맞아.
- (주)일룸 : 이사하면서 책상과 의자 산 거야.

이걸로 가계부 다시 만들어줘.
```
